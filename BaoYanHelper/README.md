# XMU保研小助手 (BaoYanHelper)

一个专业的保研申请管理平台，为学生和教师提供完整的保研申请流程管理功能。基于Figma设计精确实现，提供现代化的用户界面和流畅的交互体验。

## 功能特性

### 🎓 学生端功能
- **个人信息管理** - 查看和编辑个人资料
- **申请记录管理** - 提交、查看和管理保研申请
- **成绩单管理** - 上传和管理成绩单文件
- **规范指南** - 查看申请流程和材料准备指南
- **状态跟踪** - 实时查看申请审核状态

### 👨‍🏫 教师端功能
- **审核管理** - 审核学生申请，查看统计信息
- **学生列表** - 管理学生信息，导出学生数据
- **公告发布** - 发布重要通知和公告
- **数据管理** - 导出数据和生成统计报告

### 🌐 通用功能
- **响应式设计** - 支持桌面端和移动端
- **在线帮助** - 常见问题解答和联系方式
- **用户友好界面** - 现代化的UI设计
- **无障碍访问** - 支持键盘导航和屏幕阅读器

## 技术栈

- **HTML5** - 语义化标记
- **CSS3** - 现代CSS特性，CSS变量，Flexbox/Grid布局
- **JavaScript ES6+** - 原生JavaScript，模块化设计
- **响应式设计** - 移动优先的设计理念
- **无障碍设计** - WCAG 2.1 AA标准

## 自定义配置

### 修改主题颜色
在 `styles.css` 文件的 `:root` 选择器中修改CSS变量：

```css
:root {
  --color-primary: #your-color;
  --color-secondary: #your-color;
  /* 其他颜色变量... */
}
```

### 添加新页面
1. 在 `index.html` 中添加新的 `<section>` 元素
2. 在 `script.js` 中的 `isValidPage` 方法中添加页面名称
3. 在导航栏中添加对应的链接

### 自定义功能
在 `script.js` 中的 `handleAction` 方法中添加新的动作处理逻辑。
