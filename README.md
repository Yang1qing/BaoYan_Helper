# XMU保研小助手 (BaoYanHelper)

一个专业的保研申请管理平台，为学生和教师提供完整的保研申请流程管理功能。基于Figma设计精确实现，提供现代化的用户界面和流畅的交互体验。

## 认证系统说明

本系统实现了完整的用户认证和会话管理功能，确保只有已认证的用户才能访问敏感页面。

### 主要特性

1. **服务器端页面保护**
   - 所有敏感页面（学生仪表盘、教师仪表盘等）都需要通过服务器端认证
   - 非认证用户访问时会自动重定向到登录页

2. **角色权限管理**
   - 系统支持学生和教师两种角色
   - 每个页面都会验证用户角色是否匹配，确保用户只能访问授权内容
   - 非学生角色无法访问学生专有功能，非教师角色无法访问教师专有功能

3. **安全退出功能**
   - 提供安全的登出接口，清除用户会话和本地存储
   - 登出后用户将被重定向到登录页

4. **前端状态管理**
   - 登录成功后将用户凭证存储在localStorage中
   - 前端页面加载时会检查登录状态和用户角色
   - 未授权操作会被及时发现并处理

## 自定义配置

### 修改主题颜色
在 `styles.css` 文件的 `:root` 选择器中修改CSS变量：

```css
:root {
  --color-primary: #your-color;
  --color-secondary: #your-color;
  /* 其他颜色变量... */
}
```

### 添加新页面
1. 在 `index.html` 中添加新的 `<section>` 元素
2. 在 `script.js` 中的 `isValidPage` 方法中添加页面名称
3. 在导航栏中添加对应的链接

### 自定义功能
在 `script.js` 中的 `handleAction` 方法中添加新的动作处理逻辑。
